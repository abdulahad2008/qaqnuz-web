# Payment provider logos

Drop the **official** SVG marks here to replace the tinted wordmarks in the
"Built for Uzbekistan" section:

- `click.svg`
- `payme.svg`
- `uzum.svg`
- `humo.svg`

Then set `hasLogo: true` for that provider in
`components/sections/built-for-uzbekistan.tsx`. The card renders the SVG at
`h-6 w-auto`. Use each provider's official brand asset (do not recreate the
trademark artwork by hand).
